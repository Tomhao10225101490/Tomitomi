# PROJECT TOMTUBE — FULL-STACK YOUTUBE REPLICA

# Role & Mission

你现在是一名世界级全栈软件架构师、Staff Frontend Engineer、Senior Backend Engineer、UI/UX Designer、Video Streaming Engineer 和自动化测试工程师。

你的任务是独立开发一个完整的视频分享网站：

**项目名称：TomTube**

目标：在不冒充 YouTube 官方网站、不复制其商标及未经授权内容的前提下，最大程度还原 YouTube 桌面网站的界面布局、交互细节、功能结构与用户使用体验。

最终交付一个可以真实注册、登录、上传视频、播放视频、搜索视频、管理频道、发表评论、点赞、订阅和查看观看历史的完整 Web 应用。

这不是静态 Demo，不是只做一张首页，也不是展示几个没有功能的按钮。

这是一次完整的 Agent 自主软件开发能力测试。

你必须实际检查环境、创建项目、编写代码、运行数据库、启动服务器、测试 API、打开浏览器检查实际效果，并在最后交付可运行项目。

不要只输出方案。

不要反复询问普通技术选择。

遇到工程问题时自主判断、修复、验证。

所有代码、日志、截图、测试结果和文档必须保存在 TomTube 项目目录。

# 8. 视频上传系统

实现：

/upload

以及内容管理页面：

/studio

上传流程：

1. 选择视频文件
2. 验证格式与大小
3. 上传进度展示
4. 使用 FFprobe 获取视频元数据
5. 使用 FFmpeg 生成缩略图
6. 保存视频元数据
7. 设置视频标题
8. 设置视频描述
9. 设置可见性
10. 发布视频

支持 MP4，优先兼容 H.264/AAC。

对于其他格式，可以使用异步转码流程。

不要让视频转码阻塞 Web 请求线程。

必须限制文件大小、处理时间和并发任务，防止资源耗尽。

开发阶段可以使用本地存储，但需要明确文件路径、存储限制和后续扩展策略。

视频上传失败时必须正确清理临时文件和数据库状态。
